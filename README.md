
# Om Prakash Singh — Static Resume (GitHub Pages)

Files in this folder are a ready-to-deploy static site for GitHub Pages.

## How to deploy
1. Create a Git repository and commit these files (index.html, styles.css, script.js, Om_Prakash_Singh_R.pdf).
2. Push to GitHub. In the repository Settings → Pages, set the source to the `main` branch (or `gh-pages`) and root folder.
3. The site will be available at `https://<your-username>.github.io/<repo-name>/` shortly.

## Customize
- Edit `styles.css` variables (under `:root`) to change theme colors.
- Edit `index.html` to add or reorganize sections.
- `script.js` contains theme toggle and reveal logic.
